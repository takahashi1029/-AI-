# スクールへの反映のしかた

`exam-overview.html` は、スクールの「試験概要」と「学習プラン」の下書きです。
スクール本体（`school/`）は、わっさんのデスクトップPCにあります。そこで動いている Claude に、下の文章をそのまま貼りつけて頼んでください。

## 手順

1. このファイルと同じフォルダにある `exam-overview.html` を、デスクトップPCに持っていく
   （Google ドライブに置いてリンクを渡す、または GitHub の下のページから「Download raw file」で保存する）
   https://github.com/takahashi1029/-AI-/blob/claude/school-exam-trends-edt3im/school-drafts/exam-overview.html
2. デスクトップPCの Zed で `school` のプロジェクトを開き、Claude に下の「頼む文章」を貼る
3. 反映されたら、管理者アカウントでログインして、4つのコースそれぞれで表示を確かめる

## 頼む文章（ここから下をコピー）

```
スクール（school/）に、試験概要と学習プランを反映してください。
下書きは exam-overview.html にあります（場所：〈ここにファイルの場所かドライブのリンク〉）。

1. 試験概要
   - 下書きの <section id="exam-overview"> の中身を、今のスクールの冒頭にある「試験概要」に入れる。
   - 「試験の科目と、この塾の章」の表と、「単元ごとの出題傾向」（第1〜5章・41単元の折りたたみ表）を入れる。
   - 見た目は今のスクールのデザイン（色・フォント・部品）に合わせる。下書きの CSS は参考程度でよい。
   - 単元名は、school/public/app/content/ にある各単元の本当のタイトルと照らし合わせて、違っていたらスクール側に合わせる。

2. 学習プラン
   - 下書きの <section id="study-plan"> と <script> を参考に、今の学習プランに「1日の勉強時間」を選べる機能を入れる。
   - 選べるもの：試験日、始める日、1日の勉強時間（15分〜3時間、または分単位で自由入力）、勉強する曜日、試験2週間前からの総復習の有無。
   - 41単元を日ごとに割り振り、終わる日と、試験に間に合うか（間に合わないときは必要な1日の時間）を表示する。
   - 1単元の時間の目安：最重要60分・重要45分・標準30分（下書きの UNITS の一覧どおり）。
   - 設定は会員ごとに保存したい。ログインしている会員なら D1 に保存し、なければブラウザ（localStorage）に保存する。
   - すでに学習プランの機能があるなら、作り直さずに、そこへ追加する形にする。

3. 終わったら
   - スマホの幅で崩れないか確認する。
   - 監修チェックリストに「試験概要の出題傾向（単元ごとの重要度・よく問われる点）」の確認項目を足す。
     出題傾向は、実際の出題数を数えたものではない目安なので、監修と過去問集で確かめる必要がある。
   - 変更したファイルと、確認した内容を教えてください。本番への公開（デプロイ）は、確認してから行います。
```

## 注意
- 出題傾向は、実際の過去問の出題数を数えたものではありません。公開前に監修の先生と、受講中のスクールの過去問集で確かめてください。
- 試験の形式（各100問・60問で合格、弁証論治は記述で症例4問）は、公開されている案内をもとにしています。年度によって変わることがあります。
